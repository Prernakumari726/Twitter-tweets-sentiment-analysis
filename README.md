# Twitter Tweets Sentiment Analysis

A Deep Learning-based Natural Language Processing (NLP) project that uses a SimpleRNN neural network to classify tweets into Negative, Neutral, and Positive sentiments. The trained model is deployed using Streamlit to provide an interactive interface for sentiment prediction.

## 📌 Project Overview

This project focuses on building a sentiment classification model for tweet text using Deep Learning techniques.

The complete workflow includes:

- Data collection and exploration
- Data cleaning
- Handling missing values
- Removing duplicate records
- Sentiment label encoding
- Text tokenization
- Sequence conversion
- Sequence padding
- Train-test split
- Deep Learning model development
- SimpleRNN model training
- Model saving
- Streamlit deployment

## 🎯 Objective

The main objective of this project is to develop a Deep Learning model that can analyze the text of a tweet and classify its sentiment into:

- Negative
- Neutral
- Positive
